  Key Components:

  1. Auto-Discovery System

  - Files: Scans backend/knowledge/ and public/ directories
  - Content Analysis: Automatically detects content types (technical, experience, skills, etc.)
  - Hash Tracking: Only re-indexes changed files
  - Metadata Extraction: Adds rich metadata for smart filtering

  2. Smart Query Routing

  - Intent Analysis: Understands what users want (question, retrieval, explanation)
  - Topic Detection: Identifies relevant content areas automatically
  - Complexity Assessment: Adjusts response approach based on query complexity

  3. Unified Vector Store

  - Single Chroma Database: All content in one optimized store
  - Semantic Search: Vector similarity with intelligent filtering
  - Content Type Filtering: Routes to most relevant documents
  - Smart Scoring: Combines similarity scores with metadata relevance

  4. Intelligent Context Selection

  - Duplicate Removal: Eliminates redundant content
  - Quality Scoring: Ranks documents by relevance
  - Token Management: Fits context within model limits
  - Caching: Stores frequent query results

  5. Enhanced Response Pipeline

  - Model Fallback: Automatically switches between Claude/Gemini
  - Rate Limit Handling: Graceful degradation when models are limited
  - Follow-up Generation: Creates intelligent next questions
  - Streaming Responses: Real-time text generation

  The system requires zero manual configuration - just drop files in directories and it automatically indexes, understands, and intelligently routes queries to the most relevant
   content!
